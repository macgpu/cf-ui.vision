SOMEONE SENT YOU A MACRO?

You’re in the right place.

Install or update Ui.Vision, then return to the original shared link you received.

That page lets you view the macro and choose Add to Ui.Vision.

Shared macro links open on ai.ui.vision, Ui.Vision’s macro-sharing service.

✓ Adding a macro does not run it. You choose when to press Play.

FROM ONE PERSON TO ANOTHER

Share it. Make it yours.

  1. 01

    Send a link

    In Ui.Vision, choose Share for a macro and copy the link. Referenced helper macros, images and data files are packaged with it.

  2. 02

    Add your own copy

    Open the link, inspect the source and add it to Ui.Vision. It becomes an independent copy you can edit and keep.

  3. 03

    Run on your computer

    Check any required website logins or setup, then press Play. Macros run locally; cloud AI or OCR commands use their configured services.
