Kantu Update V2.20 adds table extraction, CSV import, Javascript support and more

May 24, 2017

The latest Kantu upgrade brings many new features - check them out:

  • Added: Visual Right-Click - Trigger and automate context menus
  • Added: Javascript command - Run content scripts inside the macro
  • Added: ReadCSV - Import data from CSV files and use with , ,… inside your macro
  • Added: Table Extraction - Save complete tables as CSV
  • Added: Image Extraction - Save every area as image
  • Added: Internal variables - Macros can do more by having access to system and web internals
  • Added: Upload all files inside a folder
  • Added: Auto-close for all Javascript dialogs (Alert, Confirm, Prompt)
  • Added: ExtractAdd - combine extracted data with custom values
  • Added: All extraction data now saved to /Download folder, in addition to the option to return it via API
  • Modified: GetExtractImageData simplified. Uses now only one separator word
  • Fixed: Recording on http://localhost websites caused a crash
  • Fixed: Several issues reported by users (thank you)

To demo the new features we expanded the Demo-Extract macro and added two new macros: Demo-Javascript and Demo-ReadCSV.

As always, you can download the latest Kantu version from https://ui.vision/download.
