Local OCR Server

NEW: As of Version 8 we managed to "squeeze" local OCR into the Windows and Mac XModules. So for these systems the use of a separate OCR server is usually not required, because the XModules already include local OCR. So since Ui.Vision Version 8 (and higher) the local OCR server is now only required if you need local OCR also on Linux machines.

Ui.Vision RPA runs 100% local and no data ever leaves your machine. You can check this easily because Ui.Vision RPA is open-source. The one exception to this rule is the OCR feature. But we understand that some organizations can not allow the use of any cloud services at all. In this case we recommend our on-premise Ui.Vision RPA OCR server installation. The Ui.Vision RPA OCR Server is a special version of the OCR.space Local On-Premise OCR Server. It runs 100% locally and requires no Internet connection. One Ui.Vision RPA Offline OCR server can be used with all Ui.Vision RPA installations in your company - so only one license is required. After the OCR server is installed, enter the URL of the server and its api key on the Ui.Vision RPA OCR settings tab. The Ui.Vision RPA OCR server is available as paid add-on for Ui.Vision RPA XModule Enterprise Edition users.

Purchasing RPA - FAQ

Q1: On how many browsers can I use the license key?

Q1: On how many browsers can I use the license key? As a developer I use on the same computer Chrome and Edge next to each other. Can I use my license key on only one or the other browser type?

A1: The licensing is per seat/PC/Mac. So you can use a license key on all browser types (Chrome, Firefox, Edge) and on each with unlimited browser profiles and it still counts only as one license.

Q2: How often can I (re-)enter a license key?

A2: You can uninstall/reinstall and re-enter your license keys unlimited times. This can be done on the same or other machines. The only limit is that not more than "X" installations of Ui.Vision RPA PRO are active (running!) at the same time. "X" is the number of licenses you purchased.

Q3: What happens after a year of free PRO upgrades? Do I have to renew?

Q3: On the top of this page it says, the license key will only cover updates on the RPA software for a year. Usually the RPA extension updates automatically without me able to prevent doing so. So what happens if RPA updates more than a year later? Do I have to buy a new license key to keep having access to the extended functionality?

While the official license information states that "only" one year of free upgrades are included we have provided free upgrades since the start - which is meanwhile more than five years ago. We have no plans to change this. So you can expect that you will receive free upgrades for the foreseeable future. We do not want to promise free upgrades "forever" since, well, our ability to look into the future is just as limited as yours. But we can sure you that if we ever start charging for upgrades it will only be for new - yet to be added - features. Our guarantee is that all currently existing features will continue to work without any further payments.

The "only" thing that will stop is the included free PRO/Enterprice level priority support. To continue getting priority support we recommend to renew your license for 25% of the license fee. However, if you choose not to do this, your software continues to work and no features are disabled.

Q4: How to move a license to a new machine?

Q4: We are moving our virtual machines to a different setup and I would like to know how we can transfer our RPA license for the same users to the new machine?

A4: Please see answer #2 above. Simply stop using RPA on the old machines and re-enter the license key on the new machines. You do not have to uninstall RPA on the old machines. Just no longer using it is sufficient.

Q5: My preferredy payment option is not listed on this page. Do you support it?

A5: Please contact us. Often we can arrange alternative payment options.

Q6: The credit card payment is not going through. What to do?

A6: Sorry about the payment issue. If our main store (this page, powered by Fastspring) has problems accepting your payment, please use our backup store (powered by Paddle, a UK-based e-commerce company). Usually all payments that are refused by Fastspring work just fine with Paddle. But if you continue to see problems, please let us know.
