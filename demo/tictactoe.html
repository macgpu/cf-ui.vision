Demo Tic-Tac-Toe

Your turn (X)
X wins: 0  |  O wins: 0  |  Draws: 0

A free, ad-free Tic-Tac-Toe game. You play X, the computer plays O (or switch to two-player mode). Every cell has a stable ID (c1…c9, numbered left to right, top to bottom) and the game state is shown in the #status element, so this page also works great as a test target for RPA macros and AI computer use agents.

Automation tips: click a cell with uiv.page.click('id=c5'), read the game state with uiv.$('id=status').text. When the game is over, the data-result attribute of #status is set to X, O or draw (empty while the game is running) — read it with uiv.eval("return document.getElementById('status').dataset.result").

The big, high-contrast X and O marks also make this page a good target for visual automation — no DOM access needed: locate a mark with image search (uiv.findImage('x.png'), or count them with uiv.findImages('x.png').length) and click the found cell with uiv.browser.click(uiv.findImage('x.png')). Or use OCR text search to watch the game state visually: uiv.ocr.findText('X wins!').
