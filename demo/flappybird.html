A free, ad-free Flappy Bird clone. Click Start, then click the game or press space to flap. Every pipe you pass scores one point. The bird falls fast, so a player (human or bot) has to react within a fraction of a second. That makes this page a fun speed benchmark for automation: a macro has to take a screenshot, find the bird and the next pipe gap, decide, and click — many times per second.

This is exactly the kind of task the new Ui.Vision for Desktop app is made for. It runs JavaScript desktop macros (*.d.js) natively, without a browser in the loop, and is therefore much faster than running the same macro inside the browser extension. Image search (uiv.findImage('bird.png')), OCR (uiv.ocr.findText('Game Over')) and native mouse and keyboard input (uiv.desktop.click(...), uiv.desktop.press('Space')) all use the same uiv.* API as in the extension.

Automation tips: the game state is mirrored into the DOM for easy testing. Start the game with uiv.page.click('id=start-button'), restart with uiv.page.click('id=restart-button'), flap with uiv.page.click('id=board') or uiv.browser.press('Space'). Read the live score with uiv.$('id=score').text (or id=final-score on the game over screen). The data-state attribute of #game is menu, ready, playing or gameover — read it with uiv.evaluate("return document.getElementById('game').dataset.state"). Tick Visual game play only to switch these helpers off: the score and state are then no longer mirrored into the DOM, and clicks or key presses dispatched by scripts (DOM automation) are ignored. Only real mouse and keyboard input counts, so the bot has to play by vision alone.

The bird and the pipes are drawn on a <canvas>, so their positions are not in the DOM. To play the game, a bot must use visual automation: find the bird with uiv.findImage('bird.png') (download the sprite here), locate the pipes with uiv.findImages('pipe.png'), and flap with uiv.browser.click(...) or, from the desktop app, uiv.desktop.click(...). Turn the sound off with the checkbox if the flap sounds get annoying during long test runs.
