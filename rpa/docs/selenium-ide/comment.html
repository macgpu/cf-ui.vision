comment - Selenium IDE command

comment adds a comment.

New: Convert a command to a comment and back with just a mouse click. The ability to comment-in (enable) or to comment-out (disable) a command is useful during macro creation.

comment Example

Command Target Pattern/Text
open https://ui.vision/
comment Anything can be put here -

Works in

Ui.Vision RPA for Chrome Selenium IDE, Ui.Vision RPA for Firefox Selenium IDE, Firefox IDE Classic
