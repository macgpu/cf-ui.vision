Ui.Vision Upgrade Completed

What's new with Version 10 (BETA)

🖱️ Browser Vision (Beta) — new B command family

  • - Added: New BClick, BClickText, BClickTextRelative, BClickRelative, BMove, BMoveText, BMoveTextRelative, BMoveRelative and BType commands: real mouse/keyboard input at browser scope — no XModule installation needed.
  • - Added: Fully XClick-compatible target resolution: images, OCR text, locators, and coordinates all work.
  • - Added: Works even when the browser window is in the background (Chrome and Edge; Firefox shows a clear "not supported" message).
  • - Added: New demo macros in a new "Browser Vision (Beta)" preinstall folder.

📌 Sidebar-first UI

  • - Added: The side panel is now the main entry point: fresh design with tabs, live status line during runs, recording, and a docked command editor. New installs default to the sidebar; the classic IDE window remains as pop-out editor.
  • - Added: New Data tab with Shots / CSV / Visual sub-tabs (replaces the Logs tab).
  • - Added: Automation tab marking: the automated page gets a colored tab group and glow border while recording/replaying, plus a green marker on the active tab while the side panel is open.
  • - Improved: Settings reorganized: General + Advanced tabs, storage mode switch, editable AI system prompt.

🤖 AI chat as macro build/fix agent

  • - Added: The AI chat builds and fixes macros directly: "create a macro to fill out this form" or "fix the current macro" work against the real editor, player, and page.
  • - Added: The agent inspects the page DOM for reliable locators, edits the macro live in the Macro tab, runs it, reads the log, and iterates on failures — with a cap on fix loops.
  • - Added: New "Fix with AI" button, chat starter prompts, and plain-language explanations of each action the agent takes.
  • - Added: The agent can capture element images itself (save_relative_image) to create image-based BClick / visualAssert / *Relative targets, with crop preview shown in chat.
  • - Added: Safety: AI-created macros are saved to a dedicated AI_Chat folder and never overwrite your macros.

🔌 AI provider choice + free tier

  • - Added: New free UI.Vision AI tier (built-in, one-time consent) — works with no API key.
  • - Added: OpenRouter and local (OpenAI-compatible) providers supported alongside Anthropic, for both AI chat and computer use — use for example the open-weight Qwen3 VL models.

How to make the Side Panel the default user interface

If you mostly replay (already existing) macros, we recommend that you make the side panel the default Ui.Vision user interface. To do so, check the "Sidepanel - make default" checkbox in the setting:


If set as default, the side panel opens directly when you click the Ui.Vision browser toolbar icon. A second click on the toolbar icon hides the side panel again.
