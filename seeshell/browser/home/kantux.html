KantuX is now SeeShell Browser

A new version of Kantux Visual Web Automation is available. It is now called SeeShell Browser. You can download the new version here.

SeeShell Browser adds new features and is fully compatible to KantuX. You only need to rename the macro file extensions from *.kmacro to *.see, and all your macros will work with SeeShell.

SeeShell Desktop Automation is here

Based on the same computer vision technologies as the SeeShell Browser for Web Automation (formerly KantuX), it applies image-driven scripting to Windows desktop automation. The SeeShell Community Edition is 100% free for both, private and commercial use, and you can download it here.
