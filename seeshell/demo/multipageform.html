Demo Form Filling

In a few seconds SeeShell will click this link, which will bring you to a regular multi-pageGoogle form, with plenty of Javascript and CSS. Once there, the SeeShell Browser fills out the forms and submits it.

The goal of this demo is to show that SeeShell is ideal for filling out multi-page forms, and it shows the use of the CLICK and CLICKTYPE commands.

The form is also used by the Demo-ManyPlay-Part1/2/3 macros, which are used by the PowerShell SeeShell Scripting API demo. You find the corresponding Powershell file in the /SeeShell.Browser/API folder or on Github. The show how to concatenate several Play API calls.
