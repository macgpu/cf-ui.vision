Ui.Vision overview: browser and desktop automation.

Have Ui.Vision Version 10? → Download the new Desktop Automation app (XModules Version 2)

Describe it. Connect your AI. Or record it yourself.

Describe it: In v10's AI macro assistant, describe what you want to automate. The assistant inspects the page, writes a macro, runs it and helps fix failures. Keep the resulting macro to edit and run again. Ui.Vision AI is available on the free plan, with no signup or API key required.

Connect your AI: Use the MCP bridge to let your own AI assistant create, run and debug Ui.Vision macros in your browser.

Record or code it: Build workflows with visual recording, Selenium-style commands, or v10's new JavaScript automation API. Combine browser commands with computer vision and OCR.

Get started with: Ui.Vision ⭳for Chrome, ⭳for Edge, or ⭳for Firefox.

Automate browser workflows on Windows, macOS and Linux. For desktop applications and local file access, add the Desktop Automation app (XModules). In Ui.Vision V10, Browser Vision on Chrome and Edge works without XModules, even with the browser window in the background.

Your macros run locally. Choose hosted Ui.Vision AI, your own AI provider, or a local model. Hosted AI sends chat content and any included page data or screenshots to the selected service for processing. Learn about AI provider choices and automation security.
