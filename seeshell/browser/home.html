SeeShell Image-Driven Automation explained


This video explains the SeeShell concept using SeeShell for Desktop Automation, but exactly the same applies to the SeeShell Browser. The key difference between SeeShell and the SeeShell Browser is that desktop automation takes over the desktop, but with the SeeShell Browser everything runs inside the SeeShell Chromium Browser. Thus you can have many instances of the SeeShell Browser running at the same time. SeeShell Browser scripts can also run in the background or even get scheduled via Windows Task Scheduler.
