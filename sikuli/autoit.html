AutoIt vs Sikuli

How is AutoIt different from Sikuli?

The key difference between Sikuli (SikuliX) and AutoIt is that Sikuli is image-driven, but AutoIt works more like a scripting language, and uses class names, process name and other Windows internal to identify Windows. Also, AutoIt is optimized for Windows, while Sikuli works on Win, Mac and Linux, but lacks deeper Windows integration.
